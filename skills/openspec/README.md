# Vendored OpenSpec skills

These `openspec-*` skill directories (and `commands/opsx/*.md`) are generated
by the OpenSpec CLI, vendored here so `/opsx:*` works in every project without
running `openspec init` per repo. They are wired user-level via
`programs.claude-code.skills` in `modules/home-manager/default.nix`; the CLI
itself is installed by `programs.claude-code-nix.extraPackages`
(`pkgs.openspec`).

Keep these in lockstep with the installed CLI version (skills call the CLI and
assume its command surface). To regenerate after a version bump:

```sh
cd "$(mktemp -d)"
openspec init --tools claude
cp -R .claude/skills/openspec-* ~/src/system-config/skills/openspec/
cp .claude/commands/opsx/*.md ~/src/system-config/commands/opsx/
```

Generated by openspec 1.4.1 (see `generatedBy` in each SKILL.md frontmatter).

Spec locations: OpenSpec reads/writes `openspec/` at the repo root. To use it
without committing specs, add `openspec/` (and `.claude/` if init was run
locally) to the repo's `.git/info/exclude`. The store feature (planning repos
that live entirely outside code repos) needs openspec >= 1.5.0 — adopt once
nixpkgs bumps past 1.4.1.
